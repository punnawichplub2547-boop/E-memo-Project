## 1. โจทย์

ฟอร์มปัจจุบันของระบบคือ **ฟอร์มซื้อ/จ้าง** (รายการที่ขอ + เปรียบเทียบราคา + งบ) แต่เมโมจริงของบริษัทมีรูปแบบหลากหลายจนใส่ฟิลด์ตายตัวไม่ไหว

จากการแกะเอกสารจริง ความหลากหลายแยกได้เป็น 3 กลุ่ม:

| กลุ่ม | ตัวอย่าง | วิธีแก้ |
|---|---|---|
| **A. วิธีคิดเงินต่างกัน** | VAT 7% + หัก ณ ที่จ่าย 3% · Freight · สกุลเงินต่างประเทศ + อัตราแลกเปลี่ยน · จ่ายเป็นงวด % | **ฟิลด์จริง** — ไม่อยู่ในงานนี้ (เฟส 0 แยกต่างหาก) |
| **B. เนื้อความและตารางประกอบต่างกัน** | ย่อหน้าอิสระ · หัวตารางคนละชุดระหว่างแผนก · รายการแนบพิมพ์เป็นข้อความ | **งานนี้** |
| **C. ช่องเซ็นไม่เท่ากันตามแผนก** | บางแผนก 4 ช่อง บางแผนก 5 ช่อง | ✅ **เสร็จแล้ว** — custom routing (V2 §1) |

**ขอบเขตของ spec นี้ = กลุ่ม B เท่านั้น**

## 2. แนวทางที่เลือก

เพิ่ม **โหมดฟอร์มที่ 2** บนหน้า `/create` คู่กับฟอร์มเดิม (ฟอร์มเดิมไม่เปลี่ยนพฤติกรรมเลย)

- เนื้อหาเป็น **block-based** — ผู้ใช้เพิ่ม/ลบ/เรียงลำดับบล็อกเอง
- เลือกโหมดนี้แล้ว **บังคับเลือกผู้อนุมัติเอง (custom route)** เพราะระบบไม่มีข้อมูลมีโครงสร้างพอจะแนะนำสายตาม Book1 ได้
- **แต่ยังคำนวณข้อเสนอแนะตาม Book1 ให้เห็น** และบังคับกรอกเหตุผลเมื่อสายที่เลือกต่ำกว่าที่แนะนำ ⇒ กันไม่ให้ฟอร์มอิสระกลายเป็นช่องเลี่ยงกฎวงเงิน

### ทำไมไม่ใช่ free-form ทั้งใบ

ถ้าเนื้อหาเป็นข้อความอิสระทั้งก้อน ระบบจะเสียความสามารถเหล่านี้ทันที: auto-route ตามวงเงิน · รายงานงบรายเดือน (`/report`) · การ map ลงเซลล์ฟอร์ม ISO · การค้นหาและ audit
จึงแยกเป็น **3 ชั้น**: core (ตายตัว ระบบใช้ตัดสินใจ) → blocks (ระบบรู้จักทุกชนิด) → เนื้อความในบล็อก (อิสระ)

## 4. ที่เก็บข้อมูล

### 4.1 เหตุผลที่แยก `form_mode` ออกมาเป็นคอลัมน์ต่างหาก

ตอนแรกตั้งใจใช้ `body_blocks_json IS NOT NULL` เป็นตัวบ่งชี้โหมด (เลียนแบบ `custom_route_json`) **แต่ทำไม่ได้** เพราะ `parseJsonArray()` (`db-memos.ts:265-270`) คืน `undefined` ทั้งกรณีคอลัมน์เป็น `NULL` และกรณี array ว่าง ⇒ ผู้ใช้ที่เลือกฟอร์มอิสระแล้วบันทึกร่างก่อนใส่บล็อก จะถูกอ่านกลับมาเป็นฟอร์มธรรมดา **โหมดหายเงียบ**

### 4.2 Migration

```sql
-- db/migrations/2026-08-17-add-memo-form-mode.sql
SET NAMES utf8mb4;
ALTER TABLE memos
  ADD COLUMN form_mode ENUM('standard','freeform') NOT NULL DEFAULT 'standard'
    AFTER custom_route_json,
  ADD COLUMN body_blocks_json JSON NULL AFTER form_mode;
```

`DEFAULT 'standard'` ทำให้เมโมเดิมทุกใบได้ค่าถูกต้องทันทีโดยไม่ต้อง migrate ข้อมูล
**ต้องเพิ่มเข้า `$ColumnMigrations` ใน `scripts/deploy-prod.ps1`** ด้วย marker `memos.form_mode` (กันซ้ำรอย migration ที่เคยตกหล่นจาก deploy script มาแล้ว 3 รอบ)

### 4.3 โครงบล็อก — ไฟล์ใหม่ `src/lib/memo-body-blocks.ts`

แยกไฟล์เพราะ `approval.ts` อยู่ที่ 695 บรรทัด ใส่เพิ่มจะทะลุ guardrail 700 (ทำแบบเดียวกับ `custom-route.ts`)

```ts
export type SystemBlockRef = "requestItems" | "priceComparison";

export type MemoBodyBlock =
  | { id: string; type: "paragraph"; text: string }
  | { id: string; type: "table"; headers: string[]; rows: string[][] }
  | { id: string; type: "keyValue"; pairs: { key: string; value: string }[] }
  | { id: string; type: "system"; ref: SystemBlockRef };
```

- `id` มาจาก `newClientRowId()` (`src/lib/client-row-id.ts`) ห้ามใช้ `Date.now()`
- บล็อกงบ ไฟล์แนบ และ short note **ไม่ได้เป็นบล็อก** — อยู่ตำแหน่งตายตัวทั้งสองโหมด

### 4.4 แนวทาง B — บล็อกระบบเก็บข้อมูลไว้ที่เดิม

บล็อก `system` เป็น **ตัวชี้ตำแหน่ง** เท่านั้น ข้อมูลจริงยังอยู่ `price_comparisons_json` / `request_items_json` เหมือนเดิม

ผลที่ได้: `computePriceRowTotals` (VAT 7%), กฎบังคับหมายเหตุจาก V2 §2, ตารางในลิ้นชักคิว, การคำนวณยอด — **ทำงานได้ทั้งหมดโดยไม่ต้องแก้**

**ข้อเสียที่ยอมรับและวิธีจัดการ:**

| ข้อเสีย | จัดการอย่างไร |
|---|---|
| ตารางอาจ render 2 ครั้ง (ตามลำดับบล็อก + ตำแหน่งเดิม) | ปิด renderer เดิมในโหมด freeform — **invariant มีเทสต์บังคับ** |
| ข้อมูลผีเมื่อลบบล็อกแต่ไม่เคลียร์คอลัมน์ | server เคลียร์คอลัมน์ให้เสมอเมื่อไม่มีบล็อก `system` ที่ผูกกัน |
| ตารางราคามีได้ชุดเดียว | ยอมรับ — ไม่พบเคสนี้ในเอกสารจริง |
| บล็อก `system` ไม่ใช่ฟังก์ชันบริสุทธิ์ | ยอมรับ — เป็นความไม่สวยของโค้ด ไม่กระทบผู้ใช้ |
| ถ้าอนาคตจะรวมเป็นก้อนเดียวต้อง migrate | ยอมรับ — เป็นทางเลือกอนาคต |

### 5.3 ตัวแก้ไขบล็อก

- ปุ่ม **↑ ↓ 🗑** ต่อบล็อก · ปุ่ม "เพิ่มบล็อก" พร้อมเมนูที่มี **บล็อกอิสระ 3 ชนิด** (ย่อหน้า · ตาราง · คู่ค่า) และ **บล็อกระบบ 2 ชนิด** (ตารางเปรียบเทียบราคา · รายการที่ขอ)
- ชนิดบล็อกระบบที่ใส่ไปแล้วจะถูกปิดในเมนู
- ตาราง: แก้หัวคอลัมน์ได้ · เพิ่ม/ลบแถวและคอลัมน์ · **เตือนเมื่อเกิน 6 คอลัมน์ ห้ามเกิน 8**
- **ไม่มีลากวางในรอบนี้** — logic การเรียงลำดับอยู่ใน pure function `moveBlock()` ⇒ เพิ่มลากวางทีหลังโดยไม่ต้องรื้อ

## 6. Excel F-DC-006

### 6.1 ลำดับในไฟล์

```
แถว 1-12   หัวกระดาษ + ตารางติ๊ก 24 แผนก        ← ไม่เปลี่ยน
แถว 13-15  เรียน… / เรื่อง / สรุปย่อ             ← ไม่เปลี่ยน
──────────  วาดตามลำดับบล็อกที่ผู้ใช้จัด  ──────────
           บล็อกงบ → ปิดท้าย → ช่องเซ็น          ← ไม่เปลี่ยน
```

บล็อกงบและช่องเซ็น **ไม่เข้าไปอยู่ในลำดับที่ผู้ใช้จัดได้** เพราะเป็นส่วนที่ ISO ตรวจ

### 6.2 Renderer

| บล็อก | วิธีวาด |
|---|---|
| ย่อหน้า | เต็ม 12 คอลัมน์ · **ตัดเป็นหลายแถวทุก ~1,200 ตัวอักษร** |
| ตารางตั้งหัวเอง | ใช้ `spanColumns(n)` |
| คู่ค่า | คีย์คอลัมน์ 1-3 (ตัวหนา) · ค่าคอลัมน์ 4-12 |
| system | เรียกฟังก์ชันวาดเดิมที่ยกออกมาเป็นฟังก์ชันย่อยรับ `r` คืน `r` |

**เหตุผลที่ต้องตัดย่อหน้า:** `fitRowHeight()` (`memo-excel.ts:117-137`) ไม่มีเพดานบน — ข้อความ 3,000 ตัวอักษรจะได้ `height = 944` ขณะที่ Excel รับได้สูงสุด ~409 point ⇒ เนื้อหาหายเงียบโดยไม่มี error

### 6.3 `spanColumns(n)`

ความกว้าง 12 คอลัมน์คือ `[5, 10, 10, 8, 8, 8, 7.5, 7.5, 9.5, 9.5, 9.5, 9.5]` รวม 102 — ไม่เท่ากัน จึง**แบ่งตามความกว้างจริง ไม่ใช่จำนวนคอลัมน์** โดยเล็งเป้าที่ `102 / n` ต่อกลุ่ม

เป็น pure function ⇒ ทดสอบครบทุกค่า n ตั้งแต่ 1 ถึง 8
**ห้ามตั้งความกว้างคอลัมน์เป็น 9 พอดี** — ExcelJS 4.4.0 มองว่าเป็นค่า default แล้วไม่บันทึกลงไฟล์ ทำให้ข้อความไทยล้นกรอบ (มีคอมเมนต์เตือนไว้ในโค้ดเดิม)

## 7. ความปลอดภัย

### 7.1 Formula injection (ช่องโหว่ที่มีอยู่เดิม)

`csvCell()` (`memo-csv.ts:19-22`) escape เฉพาะเครื่องหมายคำพูด **ไม่มีการป้องกัน formula injection** และฝั่ง Excel ก็ไม่มี ⇒ ข้อความที่ขึ้นต้นด้วย `=` `+` `-` `@` จะถูกตีความเป็นสูตรเมื่อเปิดไฟล์

วันนี้ความเสี่ยงต่ำเพราะช่องข้อความมีจำกัด **แต่ฟอร์มอิสระเปิดให้พิมพ์อะไรก็ได้ลงตารางกี่ช่องก็ได้**

⇒ **แก้ในงานนี้**: helper เดียวเติม `'` นำหน้าเมื่อข้อความขึ้นต้นด้วยอักขระเสี่ยง ใช้ทั้ง Excel และ CSV (ปิดช่องโหว่เดิมไปด้วย)

### 7.2 ด่านตรวจฝั่ง server — `src/lib/memo-body-blocks-server.ts`

เดินตามรอย `custom-route-server.ts` — ไม่เชื่อ client เลย
